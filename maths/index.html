Consignes

  • Les questions portant le symbole ♣ ont une ou plusieurs bonnes réponses. Les autres ont une unique bonne réponse.
  • Naviguez librement entre les questions avec la grille numérotée ; vous pouvez revenir sur une réponse à tout moment.
  • Cliquez de nouveau sur une case cochée (ou sur « Effacer ») pour laisser une question vide : mieux vaut 0 que −0,5 en cas de doute.
  • Le temps passé sur chaque question est mesuré.
  • Pause : le bouton « Pause » (ou la touche P) arrête le chrono et masque les questions. Tu peux même quitter la page et reprendre plus tard.
